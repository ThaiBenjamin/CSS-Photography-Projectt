# CSS Photography Site

A photography portfolio page built with plain HTML and CSS — a hero section, an image
gallery, and consistent typography, with all the styling in a single `photos.css`.

## What I took from it

A photography site is a good CSS problem because the images have to carry the page visually
while the structure stays out of the way. That's a different exercise from the utility
layouts I'd been practicing, where the structure *is* the point.

It pushed me to think about white space as something you place deliberately rather than
whatever is left over. Given a grid of photos, the spacing between them changes how the page
reads more than any individual style rule does.

Writing every style by hand with no Bootstrap also made clear exactly how much a framework
does for you. Things like consistent vertical rhythm and sane defaults for image sizing are
invisible until you're the one specifying them.
