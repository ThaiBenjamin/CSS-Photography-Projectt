# 📷 CSS Photography Site

A styled photography portfolio page built with pure HTML and CSS — practicing layout, typography, and visual presentation for an image-heavy website.

---

## 📚 What I Was Learning

Applying CSS layout and styling techniques to a real-world design pattern — a photography portfolio site with a hero section, image gallery, and consistent typography.

---

## 🔑 Key Things Practiced

- **CSS Layout** — Positioning elements for a visually structured portfolio page
- **Typography** — Font pairing, sizing hierarchy, and spacing for readability
- **Image Presentation** — Styling images within a gallery grid
- **Custom CSS Styling** — Writing a standalone `photos.css` without a framework

---

## 💡 What It Taught Me

A photography portfolio is a great CSS challenge because the images need to carry the page visually while the structure stays clean and out of the way. This project pushed me to think about white space and visual balance more carefully than utility exercises. Writing all the styles in a single custom CSS file — no Bootstrap, no shortcuts — deepened my understanding of what a framework actually handles for you.
